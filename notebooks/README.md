# Exploración reproducible

Espacio reservado para cuadernos de auditoría, visualización y análisis de errores. No hay cuadernos científicos iniciados en esta entrega.

Los futuros cuadernos deben ejecutarse desde un kernel del entorno uv, cargar configuraciones y reutilizar funciones de `src/mars_titan/`. Mantener una pregunta por cuaderno, registrar entradas y cortar explícitamente la información temporal. Evitar salidas voluminosas, secretos y lógica científica que solo exista en una celda.
