# Procedencia y condiciones de uso

La copia local de FinMultiTime precede a esta preparación. Su revisión original
de adquisición no está acreditada. El manifiesto identifica el contenido disponible
mediante hashes, sin inventar un identificador remoto de descarga.

El README distribuido con el dataset declara MIT. Esa indicación no acredita por
sí sola los derechos de cada noticia, imagen o dato subyacente. El proyecto mantiene
fuentes y derivados fuera de Git y no autoriza su redistribución por heredar la
licencia del código.

Las descargas macro proceden del formulario público de ALFRED. Cada ZIP conserva
su README, proveedor, intervalos y aviso de derechos. Las condiciones de las series
pueden diferir. Los informes publicados describen recuentos, comprobaciones y
recursos, no redistribuyen el archivo de observaciones.

Los pesos de MiniLM se descargan de la revisión registrada de su repositorio
oficial, cuya ficha declara Apache 2.0. Los pesos de ResNet18 proceden de PyTorch.
Las condiciones del código de una biblioteca no se trasladan automáticamente a
los datos usados para preentrenar sus pesos. No se versionan pesos ni embeddings.

Antes de distribuir datos o representaciones se deberá revisar el permiso concreto
de cada fuente. Esta preparación permite investigación local y trazabilidad, no
constituye una autorización de redistribución de materiales de terceros.
