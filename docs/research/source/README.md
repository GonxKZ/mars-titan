# Propuesta técnica inicial

La copia local `initial-proposal.pdf` conserva sin cambios el documento de investigación aportado por Gonzalo García Lama. Sus 45 páginas incluyen una propuesta de arquitectura, figuras conceptuales y referencias anteriores a esta preparación.

El archivo no se publica con el repositorio. Su huella está en el [manifiesto de documentos](../../academic/source-manifest.json). La [revisión crítica](../original-review.md) identifica qué ideas se mantienen, qué afirmaciones necesitan precisión y qué componentes deben evaluarse antes de sostener una conclusión.
