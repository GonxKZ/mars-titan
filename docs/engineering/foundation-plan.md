# Plan de preparación del repositorio

**Objetivo:** dejar lista la base documental y técnica para desarrollar la comparativa MARS-TITAN.

**Arquitectura:** monorrepositorio por responsabilidades. Datos y biblioteca local fuera de Git. Bibliografía, protocolos y código versionados.

**Tecnologías:** Python con uv, CMake C/C++/CUDA, pytest, Ruff, Markdown, BibTeX, LaTeX y GitHub Actions.

**Diseño:** [foundation-design.md](foundation-design.md).

## Restricciones comunes

Español académico natural. Autor Gonzalo García Lama. Seis objetivos sin carpetas por fase. Licencia MIT para material propio. No publicar datos ni PDF de terceros. Commits y ramas convencionales en inglés. CUDA explícita para aprendizaje profundo.
